# Routes

TanStack Router uses file-based routing. Every route `.tsx` file in this
directory is included in the generated route tree. `routeTree.gen.ts` is
generated by the Vite Router plugin; do not edit it by hand.

| File | URL |
| --- | --- |
| `index.tsx` | `/` |
| `about.tsx` | `/about` |
| `users/index.tsx` | `/users` |
| `users/$id.tsx` | `/users/:id` |
| `posts/{-$category}.tsx` | `/posts/:category?` |
| `files/$.tsx` | `/files/*` |
| `__root.tsx` | App root layout; renders nested routes through `<Outlet />` |

This frontend is a client-rendered SPA. Production hosting must return
`index.html` for non-file app routes so TanStack Router can resolve direct
navigations and page refreshes.
